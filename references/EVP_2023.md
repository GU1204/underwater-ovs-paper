# EVP（2023）论文写作脉络

> **论文**：*Explicit Visual Prompting for Low-Level Structure Segmentations*  
> **作者**：Weihuang Liu, Xi Shen, Chi-Man Pun, Xiaodong Cun  
> **会议**：CVPR 2023  
> **方法名**：Explicit Visual Prompting（EVP）  
> **核心设计**：Patch Embedding Tune + High-Frequency Components Tune + Adaptor

## Abstract

- **[2]** 作者先把伪造区域、失焦区域、阴影和伪装目标归入统一的 **low-level structure segmentation**，强调这些任务过去通常依赖各自的专用网络；这一开场先建立“多个不同任务能否由统一方法解决”的论文问题。
- **[2]** 从 NLP 的“预训练模型 + prompt tuning”范式引出 EVP，并与已有 visual prompting 区分：已有方法多学习 dataset-level 的隐式 embedding，EVP 要让可训练参数直接依赖每张输入图像的显式视觉内容。
- **[2]** 将显式内容具体落到 frozen patch embedding 和输入图像的 high-frequency components，两类特征提前对应后文的 Embedding Tune 与 HFC Tune。
- **[2]** 用仅增加约 5.7% 可训练参数、优于其他 parameter-efficient tuning 和多个 task-specific 方法收尾；性能与参数量同时出现，用来确立“统一 + 高效”两条贡献线。

## 1. Introduction

- **[3]** 从图像篡改检测切入，引用 JPEG compression、noise inconsistency 等经典线索说明伪造区域往往体现在低层统计差异；随后把 blur、shadow、camouflage 也纳入同一观察，建立四个任务共享 low-level clues 的依据。
- **[2]** Figure 1 上半部分把 camouflage、forgery、shadow、defocus blur 四个任务并列展示；图的作用不是解释网络细节，而是先把原本分散的研究问题视觉上统一成一类 segmentation task。
- **[2]** 作者指出这些任务虽然共享低层结构特征，却通常由 domain-specific architecture 单独处理，并受到训练数据规模有限的影响；这段为“为什么值得用一个预训练 backbone 统一解决”提供问题背景。
- **[3]** 引用 NLP prompting、VPT、AdaptFormer 等工作介绍参数高效迁移：冻结大规模预训练模型，只为下游任务学习少量参数；作者强调这种范式在标注有限时具有泛化和存储优势，为冻结 backbone 的选择提供依据。
- **[2]** 作者给出全文最关键的判断：预训练模型已经拥有足够的 semantic understanding，下游 low-level segmentation 不必重新学习全部语义，只需要从**当前图像本身**提取 task-specific knowledge。
- **[2]** 用 SIFT、JPEG noise、resampling artifacts 等 hand-crafted features 的历史有效性支撑上述判断；这些引用的目的不是复用具体特征，而是证明低层、图像相关线索确实长期有效。
- **[3]** 基于这一观察提出 EVP，并把输入信息拆成两类：frozen patch embedding 用于调整预训练域到目标任务的 feature distribution，高频分量用于补回预训练视觉模型在数据增强中被刻意学成不敏感的信息。
- **[2]** Figure 1 下半部分展示 frozen transformer、Embedding Tune、High Frequency Tune 和逐层 prompt 注入；图在 Introduction 就提前给出“冻结主干 + 图像显式特征生成 prompt”的整体逻辑。
- **[2]** 用九个数据集、四个任务预告实验范围，并强调同一网络无需 task-specific modification；这一句为后文跨任务统一实验设置做铺垫。
- **[3]** 贡献列表依次总结统一 low-level segmentation 框架、EVP 的两类显式视觉提示、与专用方法相当或更优的性能；贡献结构保持“问题统一—方法设计—实验验证”的顺序。

## 2. Related Work

### Visual Prompting Tuning

- **[3]** 作者从 NLP prompting 回顾到视觉领域的 memory token 和 VPT，说明 learnable embedding 已被证明可以在冻结 Transformer 上完成任务迁移；引用 VPT 的主要目的，是建立本文最直接的 prompt-tuning 对照。
- **[1]** 作者随后明确差异：VPT 主要验证 recognition task 上的隐式 prompt，而本文关心的是 low-level structure segmentation 中什么**显式视觉内容**最适合作为 prompt。

### Forgery Detection

- **[3]** 先回顾 noise inconsistency、SIFT、JPEG compression、resampling artifacts 等传统 forensic clues，再列举 FCN、GAN、TransForensics 等深度方法；这一脉络持续强化“伪造检测本身依赖低层异常”的事实。
- **[2]** 引用 RGB-N 和 ObjectFormer 使用 noise/high-frequency stream 作为 complementary signal，说明高频先验在现代模型中仍有效；作者紧接着区分本文不是设计一个 forgery-specific 高频分支，而是把 HFC 变成可迁移到多任务的 prompting signal。

### Defocus Blur Detection

- **[3]** 从 gradient、edge 等手工特征回顾到 CNN、multi-scale fusion、depth supervision 和 ensemble 方法；引用对象共同说明失焦检测长期依赖边缘和局部结构，而现有方案越来越复杂。
- **[1]** 这部分没有单独引出新模块，而是为“同一 EVP 能否替代专门的 blur detector”准备实验对照。

### Shadow Detection

- **[3]** 先介绍 illumination 和 hand-crafted feature，再回顾 CNN、direction-aware attention、distraction-aware module、lighting prior 和 semi-supervised 方法；这一段强调 shadow detection 同样大量依赖低层光照线索和定制模块。
- **[1]** 相关工作的写法继续累积“任务不同，但都在手工设计如何利用低层信息”的证据，为统一 prompting 框架服务。

### Camouflaged Object Detection

- **[3]** 从 texture、brightness、color 等低层线索回顾到 SINet、PFNet、FBNet 等深度方法；引用 FBNet 的 frequency modeling 说明频域信息也被用于 camouflage detection。
- **[1]** 四个任务的相关工作最终形成同一结论：各领域方法结构不同，但都依赖某种 low-level cue，给 EVP 的跨任务共享设计提供文献支撑。

## 3. Method

- **[2]** 方法开头先定义 EVP 的整体目标：用 ImageNet 预训练的 Vision Transformer 适配 low-level structure segmentation，同时冻结 backbone，仅学习少量参数。
- **[2]** 作者说明这些参数只从 frozen image embedding 和 HFC 中学习 task-specific knowledge；这一句把 Introduction 的核心假设正式变成方法约束。
- **[1]** 方法组织先介绍 SegFormer 与 HFC extraction，再介绍 EVP architecture；写作顺序是“先定义可利用的信息源，再说明如何生成 prompt”。

### 3.1 Preliminaries — SegFormer

- **[2]** 先介绍 SegFormer 的 hierarchical Transformer 和多尺度 feature extraction，解释为什么它适合作为统一 dense prediction backbone；引用 SegFormer [77] 的目的主要是固定基础网络，而不是把 backbone 本身作为贡献。
- **[1]** 作者明确 EVP 不依赖 SegFormer，也能迁移到 ViT、Swin 等结构；这一声明提前为后面的 SETR/plain ViT 实验埋下验证点。

### 3.1 Preliminaries — High-Frequency Components

- **[2]** Figure 2 展示 HFC 的生成流程：对输入图像做 FFT，将低频移动到频谱中心，屏蔽中心低频区域，再通过 IFFT 得到高频图像；图承担“高频 prompt 从哪里来”的算法说明作用。
- **[2]** 公式 (1) 用 mask ratio \(\tau\) 定义频谱中的高频保留区域，公式 (2) 将掩膜后的频谱逆变换为 \(I_{\mathrm{hfc}}\)；两个公式把“high-frequency cue”从概念描述变成固定、无需学习的显式预处理。
- **[1]** 公式 (3)–(4) 对称定义 LFC，主要服务于后续频率成分分析和消融，而不是 EVP 主分支必须使用的输入。
- **[1]** RGB 三个通道独立进行频域处理，补充 HFC extraction 的实现细节。

### 3.2 Explicit Visual Prompting

- **[3]** 小节开头重新解释两类 prompt 的分工：patch embedding 用于 shift pre-training 与 downstream distribution，HFC 用于恢复预训练模型因 data augmentation 而被弱化的低层高频信息；这一段直接回答“为什么偏偏选择这两个输入”。
- **[1]** 作者再次与 VPT 对比，强调 VPT 学的是 dataset-level implicit prompt，而 EVP 的 prompt 由当前图像内容显式生成。
- **[2]** Figure 3 将 EVP 拆成 **Patch Embedding Tune、HFC Tune、Adaptor** 三部分，并显示 prompt 被加到各 Transformer layer；图承担整个方法最主要的结构解释。

#### Patch Embedding Tune

- **[2]** 冻结 SegFormer 原始 patch projection，再增加可训练线性层 \(L_{\mathrm{pe}}\) 将 patch embedding 压缩到 \(c\) 维，得到 \(F_{\mathrm{pe}}\)；这种写法保留预训练表征，只允许一个低维旁路学习任务偏移。
- **[2]** 公式 (5) 定义
  \[
  F_{\mathrm{pe}}=L_{\mathrm{pe}}(I^p),\qquad c=C_{\mathrm{seg}}/r
  \]
  并用 \(r\) 控制可训练参数量；公式同时承担 feature projection 与 parameter-efficiency trade-off 的定义作用。

#### High-Frequency Components Tune

- **[2]** 将 \(I_{\mathrm{hfc}}\) 按与 SegFormer 相同的 patch size 切分，再通过可训练线性层 \(L_{\mathrm{hfc}}\) 投影到同样的 \(c\) 维空间；这样 HFC 可以与 patch embedding 在统一表示空间中融合。
- **[1]** 公式 (6) 定义 \(F_{\mathrm{hfc}}=L_{\mathrm{hfc}}(I^p_{\mathrm{hfc}})\)，把固定频域先验转换成可随下游任务学习的 prompt feature。

#### Adaptor

- **[2]** Adaptor 接收 \(F_{\mathrm{pe}}\) 与 \(F_{\mathrm{hfc}}\)，目标不是重新编码图像，而是把两类显式特征转换为每一层 Transformer 可使用的 prompt。
- **[3]** 公式 (7)
  \[
  P^i=\mathrm{MLP}_{\mathrm{up}}
  \big(\mathrm{GELU}(\mathrm{MLP}^{i}_{\mathrm{tune}}(F_{\mathrm{pe}}+F_{\mathrm{hfc}}))\big)
  \]
  先用每层独立的 \(\mathrm{MLP}^{i}_{\mathrm{tune}}\) 产生 layer-specific prompt，再用所有 Adaptor 共享的 \(\mathrm{MLP}_{\mathrm{up}}\) 恢复 Transformer feature dimension；公式完整定义“图像显式线索 → 层级 prompt”的生成过程。
- **[2]** 每层独立 tune layer 保留不同 Transformer 层对 task-specific information 的差异需求，共享 up-projection 控制额外参数；这个结构取舍后面由 Table 7 专门消融验证。
- **[1]** 输出 \(P^i\) 直接附加到对应 Transformer layer，使冻结 backbone 在不修改原参数的条件下接受当前图像相关的任务提示。

## 4. Experiment

### 4.1 Datasets

- **[3]** Table 1 汇总九个数据集，并按 forgery、shadow、defocus blur、camouflaged object 四类任务组织训练/测试数量；表格的写作作用是强调实验横跨多个视觉问题，而不是在一个 benchmark 上证明效果。
- **[2]** Forgery 使用 CASIA 训练并在 CASIA、IMD20 测试；加入真实世界 IMD20 可以检查方法是否只适应训练集中的 manipulation pattern。
- **[2]** Shadow 使用 ISTD、SBU，Defocus 使用 CUHK、DUT，Camouflage 使用 COD10K、CAMO、CHAMELEON；作者沿用各领域已有 protocol 和指标，保证统一网络可以直接与各自 task-specific SOTA 比较。

### 4.2 Implementation Details

- **[3]** 统一采用 ImageNet-1K 预训练 SegFormer-B4，冻结 backbone，根据任务使用 BCE、balanced BCE 或 BCE+IoU loss；作者只改变任务所需的标准 segmentation loss，避免通过额外专用网络解释性能提升。
- **[2]** 单张 Titan V、batch size 4、AdamW 等设置说明 EVP 的训练规模较轻；实现细节与全文“parameter-efficient adaptation”主张一致。

### 4.3 Main Results — Task-Specific Methods

- **[3]** Table 2–5 分别与 defocus blur、shadow、forgery、camouflage 的专用方法比较；作者没有先把四个任务平均成单一数字，而是逐领域证明同一 EVP 能进入各自的 SOTA 对比体系。
- **[2]** EVP 在九个数据集中的五个取得最佳结果，并在其余数据集保持竞争力；作者把结果解释为 frozen strong backbone 与 prompting strategy 的共同作用，而不是声称所有任务都绝对领先。
- **[2]** Figure 4 每个任务各选择专用 baseline 做 mask 可视化，展示 EVP 在 camouflage、forgery、shadow、defocus blur 中都能产生更完整或更准确的区域；定性结果承担“统一模型并未牺牲像素级结构质量”的补充证据。

### 4.3 Main Results — Efficient Tuning Methods

- **[3]** Table 6 把 EVP 与 full-tuning、only decoder、VPT-Deep、AdaptFormer 放在相近可训练参数规模下比较；这一表不是和领域 SOTA 比，而是专门回答“显式 prompt 是否比普通 parameter-efficient tuning 更适合 low-level segmentation”。
- **[2]** Only Decoder 明显退化，说明冻结 backbone 后只训练 segmentation head 不足以完成 domain/task adaptation；作者用它证明中间 Transformer 表征仍需要被调制。
- **[2]** VPT 和 AdaptFormer 能改善性能，但相同参数量下 EVP 更强；对比用于支持“从当前图像提取 explicit low-level content”比仅增加 learnable token 或通用 MLP 更有效。
- **[2]** \(r=16\) 用来与其他 PEFT 方法做近似公平的参数比较，\(r=4\) 展示增加少量参数后的性能上限，并在四个代表数据集中的三个超过 full-tuning；这组设置同时验证效率与性能。

## 4.4 Ablation Study

### Architecture Design

- **[3]** Table 7 从 Decoder baseline 开始，分别移除 \(F_{\mathrm{pe}}\)、移除 \(F_{\mathrm{hfc}}\)、共享 \(\mathrm{MLP}^{i}_{\mathrm{tune}}\)、取消共享 \(\mathrm{MLP}_{\mathrm{up}}\)；消融项与 Figure 3 的每个结构选择逐一对应。
- **[2]** 删除 patch embedding prompt 或 HFC prompt 都导致多任务性能下降，用来证明两类显式信息具有互补作用，而不是其中一条分支单独决定增益。
- **[2]** 跨 Adaptor 共享 \(\mathrm{MLP}^{i}_{\mathrm{tune}}\) 虽减少少量参数，却带来明显性能下降；该结果支撑不同 Transformer 层需要不同 task-specific modulation。
- **[2]** 为每个 Adaptor 使用独立 \(\mathrm{MLP}_{\mathrm{up}}\) 增加较多参数却没有稳定收益；作者据此保留“layer-specific tune + shared up-projection”的最终结构。
- **[2]** Figure 5 在 ISTD 上把 Full-tuning、无 prompt、去除不同分支和不同共享策略的预测并列展示；图的作用是把 Table 7 的数值差异落到 shadow boundary 和区域完整性上。

### Tuning Stage

- **[3]** Table 8 从只在 Stage 1 加 prompt，逐步扩展到 Stage 1–4，性能随被 prompt 的 stage 增加而改善；这一实验回答“EVP 应该只调浅层低级特征，还是贯穿 backbone”。
- **[2]** Stage 1,2 → Stage 1,2,3 的提升最大，作者结合 SegFormer-B4 第三阶段包含 27 个 Transformer blocks 解释结果；实验支持 EVP 效果与被调制 block 数量正相关。
- **[1]** 这一结果也避免把“low-level structure”误解为只需要浅层 feature：低层显式线索需要通过多层 Transformer 持续影响最终表征。

### Scale Factor \(r\)

- **[3]** Table 9 从 \(r=64\) 到 \(r=1\) 扫描瓶颈维度，直接展示参数量与性能的关系；\(r\) 越小，adapter 容量越大。
- **[2]** 从 64 降到 4 时多数任务持续改善，继续增大模型到 \(r=2,1\) 后收益不再稳定；作者据此选择 \(r=4\) 作为效率和性能的平衡点，而不是单纯追求更多参数。

### EVP in Plain ViT

- **[3]** Table 10 将 backbone 从 hierarchical SegFormer 换成 SETR 的 plain ViT，并再次比较 Full-tuning、Decoder、VPT、AdaptFormer 与 EVP；这一实验专门验证前文“EVP 不依赖 SegFormer”的声明。
- **[2]** EVP 在 plain ViT 上仍优于其他 tuning 方法，说明核心增益来自 explicit visual prompting 本身，而不是 SegFormer 的多尺度层级结构。

## 5. Conclusion

- **[2]** 结论重新回到“统一 low-level structure segmentation”这一开篇命题，用 frozen patch embedding 和 image HFC 概括 EVP 的两个核心信息源，不再引入新模块。
- **[2]** 作者用少量可训练参数即可接近 full-tuning、并与 task-specific SOTA 竞争作为最终证据，收束“预训练语义知识保留 + 显式低层信息补充”的核心观点。
- **[1]** 未来工作只提出扩展到更多相关问题，延续论文把 EVP 定位为通用 visual prompting 机制的方向。

## 整体写作主线

- **先把四个看似独立的任务统一起来**：Forgery、Defocus Blur、Shadow、Camouflage 都需要分割低层结构，并且已有研究都长期依赖 noise、frequency、gradient、texture、illumination 等 low-level clues。
- **再把“统一模型”的合理性落到预训练模型上**：作者认为 ImageNet 预训练 Transformer 已经拥有足够 semantic knowledge，有限下游数据不值得重新训练整个 backbone。
- **核心转折是从 implicit prompt 改成 image-specific explicit prompt**：VPT 学一组与具体输入无关的参数，EVP 则从每张图像的 frozen patch embedding 和 HFC 生成 prompt。
- **两类输入承担不同写作角色**：Patch embedding 解决 pretrained distribution 与 downstream task 的偏移，HFC 补充预训练过程中容易被忽略、但对 low-level structure 很关键的细节。
- **方法结构围绕“低成本逐层注入”展开**：Embedding Tune/HFC Tune 先降维，layer-specific tune MLP 生成不同层 prompt，共享 up-projection 控制参数量，再把 prompt 注入冻结 Transformer。
- **实验分成两条证据链**：Table 2–5 与 task-specific SOTA 比较，证明“统一模型也能做好各任务”；Table 6 与 Full-tuning/VPT/AdaptFormer 比较，证明“显式 prompt 比一般 PEFT 更适合这些任务”。
- **消融严格回扣结构设计**：Table 7 验证两种 prompt 和 MLP 共享策略，Table 8 验证提示层数，Table 9 验证参数瓶颈，Table 10 验证跨 backbone 泛化。
- **全文最核心的写作模式是**：共享低层线索 → 专用方法过于分散 → 冻结预训练语义能力 → 从当前图像提取显式低层信息 → 用少量参数把这些信息逐层注入 → 用四类任务证明统一性。
