# 论文工作区

本目录按论文工作流分为四类：

- `writing/`：论文正文、提纲、审阅记录与写作提示词
  - `abstract/`：摘要草稿
  - `intro/`：引言草稿
- `design/`：模型结构、模块方案、迁移方案与实现说明
- `datasets/`：数据集说明、类别统计、类别名称及相关表格
- `references/`：论文阅读笔记、相关工作与写作思路

## 当前入口

- 摘要草稿：`writing/abstract/1.md`
- 引言草稿：`writing/intro/1.md`
- 写作蓝图：`writing/writing_blueprint.md`
- 问题定义：`writing/Problem formulation.docx`
- 研究资料汇总：`design/research_dossier.md`
- 数据集划分：`datasets/数据集划分.md`

## 整理约定

1. 新的正文草稿放入 `writing/` 下对应章节目录。
2. 模型结构、实验方案和源码说明统一放入 `design/`。
3. CSV、Excel、类别表及数据集说明统一放入 `datasets/`。
4. 单篇论文笔记和相关工作材料统一放入 `references/`。
5. 暂不随意重命名已有文件，避免破坏文档内引用。
